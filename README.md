# TTRPG Dictaphone — «Хроники»

Mobile-first PWA для голосового журнала TTRPG-кампаний. Данные MVP хранятся локально в браузере; ключи AI остаются только на Node.js-сервере.

## Возможности

- локальная регистрация и вход (однопользовательский MVP);
- несколько независимых кампаний, роли `PLAYER` и `GM`, создание, изменение и удаление;
- запись с микрофона и загрузка `webm`, `mp3`, `m4a`, `wav`, `ogg`;
- транскрибация русской речи через Groq Whisper;
- редактируемые raw/normalized transcript, блоки `B001…`;
- Gemini-анализ, summary, `Previously on…` и предложения сущностей;
- Review: AI ничего не записывает в энциклопедию без подтверждения;
- ручной CRUD энциклопедии, aliases, facts, visibility и provenance;
- поиск по сущностям, фактам, транскрипциям и summary;
- безопасный импорт `.md`/`.txt`, экспорт кампании в JSON и Markdown;
- PWA/offline shell и светлая/тёмная тема.

## Требования

- Node.js 22+ (проверено на Node.js 24);
- npm;
- современный браузер. Микрофон доступен только на `localhost` или HTTPS;
- Groq API key и Gemini API key с доступной бесплатной квотой.

## Настройка

```bash
npm install
cp .env.example .env
```

Откройте `.env` и заполните:

```dotenv
GROQ_API_KEY=ваш_ключ_groq
GROQ_TRANSCRIPTION_MODEL=whisper-large-v3
GEMINI_API_KEY=ваш_ключ_gemini
GEMINI_MODEL=gemini-2.0-flash
PORT=3000
```

`.env` включён в `.gitignore`. Не добавляйте ключи в `VITE_*`, frontend-код или Git. Если ключ был опубликован, отзовите его и создайте новый.

## Рекомендуемый запуск

Production-like режим запускает API и собранный frontend на одном адресе:

```bash
npm run build
npm start
```

Откройте <http://localhost:3000>. Проверка конфигурации:

```bash
curl http://localhost:3000/api/health
```

Ожидается:

```json
{"ok":true,"transcriptionConfigured":true,"analysisConfigured":true}
```

### Режим разработки

Vite и API запускаются в двух терминалах. Vite проксирует `/api` на порт 3000:

```bash
# Терминал 1
npm start

# Терминал 2
npm run dev
```

Откройте адрес Vite, обычно <http://localhost:5173>.

## Как выполнить транскрибацию

1. Зарегистрируйтесь и создайте кампанию.
2. Нажмите **Новая сессия**.
3. Укажите название и дату.
4. Нажмите круглую кнопку микрофона; разрешите браузеру доступ. Нажмите снова для остановки. Вместо записи можно загрузить аудиофайл.
5. Прослушайте файл и нажмите **Транскрибировать через Groq**.
6. Исправьте текст в поле транскрипции и сохраните сессию.
7. На странице сессии нажмите **Запустить AI-анализ**.
8. Отредактируйте summary/recap, примите или отклоните каждое предложение и нажмите **Применить выбранные изменения**.

Если бесплатная квота исчерпана, UI покажет `AI_FREE_QUOTA_EXCEEDED`. Аудио на текущей странице и текст не удаляются; операцию можно повторить позже. Автоматического платного fallback нет.

Frontend отправляет запись как multipart-поле `file`. Сервер заново собирает запрос, добавляет модель из `GROQ_TRANSCRIPTION_MODEL` и отправляет его в Groq; вручную добавлять модель или переименовывать файл не требуется.

## Данные и ограничения MVP

Аккаунты и данные сохраняются в `localStorage` конкретного браузера. Это соответствует локальному однопользовательскому MVP, но не является production-аутентификацией или серверной синхронизацией. Используйте экспорт JSON/Markdown как резервную копию. Очистка данных сайта удалит локальную базу.

GM-only сущности исключаются из интерфейса игрока до поиска и подготовки контекста. Каждая кампания фильтруется по `campaignId`, поэтому данные кампаний не смешиваются.

## Устранение неполадок

- **`TRANSCRIPTION_NOT_CONFIGURED`** — нет `GROQ_API_KEY` в `.env` либо сервер запущен не через `npm start`.
- **`AUDIO_FILE_REQUIRED`** — сервер не получил multipart-поле с файлом; обновите приложение и service worker, затем перезагрузите страницу.
- **`unknown file audio`** — это сообщение старой версии клиента, которая отправляла поле `audio` вместо обязательного поля `file`; выполните новую сборку и принудительно обновите страницу.
- **`AI_ANALYSIS_NOT_CONFIGURED`** — не задан `GEMINI_API_KEY`.
- **`AI_FREE_QUOTA_EXCEEDED`** — бесплатная квота провайдера исчерпана; повторите позднее.
- **Микрофон не открывается** — используйте `localhost`/HTTPS и проверьте разрешения сайта.
- **Vite возвращает 404 на `/api`** — одновременно запустите `npm start`; proxy настроен на `127.0.0.1:3000`.
- **После изменения `.env` ничего не изменилось** — перезапустите Node.js-сервер.
